# GATHER — Product Showcase

**You've got the products. We've got the gallery.**

GATHER is a seller-side product showcase designed to bring products together in one organized, visually appealing storefront. Sellers can add product details, display product cards, manage their product listings, and update stock status through a simple interface.

**Live Demo:** [GATHER — Storefront](https://madhushreerasal.github.io/GATHER---Storefront/)

## Features

- **Dynamic Product Cards** — Generate product cards from user-entered details.
- **Add Products** — Add products to the beginning or end of the gallery.
- **Remove Products** — Remove the first or last product from the gallery.
- **Stock Status Management** — Mark products as out of stock.
- **Product Details** — Display product ID, category, name, image, description, and price.
- **Responsive Layout** — Adapt the interface to different screen sizes.
- **Interactive Interface** — Update the displayed gallery dynamically using JavaScript.

## Technologies Used

- **HTML5** — Page structure and product input form.
- **Tailwind CSS** — Styling and responsive layout.
- **JavaScript** — Product data management, array operations, and dynamic DOM updates.
- **Remix Icon** — Interface icons.
- **GitHub Pages** — Deployment and hosting.

## Current Scope

GATHER currently demonstrates client-side product showcasing and basic product management. Product data is maintained in a JavaScript array during the active page session.

Features such as user accounts, persistent storage, checkout, payment processing, and backend integration are not currently implemented.
